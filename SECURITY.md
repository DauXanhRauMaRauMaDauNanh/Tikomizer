# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Tikomizer, please do not disclose it publicly on GitHub issues.

Please send an email detailing the vulnerability, reproduction steps, and potential impact to the project author (Mtienn) via GitHub private vulnerability reporting. We aim to acknowledge receipt within 48 hours and provide a patch promptly.
